# Awak Will 觉醒意志 - 智能戒指官网

全球首款自适应智能戒指的官方网站首页，采用现代化设计，突出科技感和健康关怀理念。

## 项目特点

- 🎨 **科技感深色主题**：采用深色背景配合亮色点缀，营造专业科技氛围
- 📱 **完全响应式设计**：适配桌面、平板和移动设备
- ✨ **丰富的交互效果**：滚动动画、悬停效果、视差滚动等
- 🚀 **性能优化**：使用现代CSS和JavaScript，确保流畅体验
- 🌐 **多语言支持**：支持中英文切换（框架已搭建）

## 设计规范

### 色彩方案
- **主色调**：科技蓝 (#00D4FF)
- **强调色**：金黄色 (#FFD700)
- **背景色**：深色渐变 (#0A0E27 → #050710)
- **文字色**：白色/浅灰色层级

### 字体
- **主字体**：Inter（Google Fonts）
- **标题**：加粗，大字号
- **正文**：中等字号，易读性强

### 交互效果
- 悬停动画
- 滚动触发动画
- 平滑滚动
- 视差效果

## 使用方法

1. 直接在浏览器中打开 `index.html` 即可查看
2. 或使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js (需要安装http-server)
   npx http-server
   ```
3. 访问 `http://localhost:8000`
