## 一、我们收集哪些信息

我们遵循「最小必要」原则收集信息。健康相关数据属于**敏感个人信息**，我们仅在提供对应功能所必需且获得您授权后收集。

### 1.1 您主动提供的信息

| 类型 | 内容 | 用途 |
|------|------|------|
| 账号信息 | 手机号码、验证码、昵称、头像、性别、身高、体重、出生日期；使用**本机号码一键登录**时，经运营商网关与阿里云号码认证服务核验的本机手机号码 | 注册登录、健康指标计算、资料展示 |
| 紧急联系人 | 姓名、电话号码（由您选填） | 仅在您主动配置的安全相关场景使用 |
| 反馈与客服 | 文字、图片等您提交的内容 | 问题处理与客服回访 |
| 营养记录 | 饮食文字、拍照识别相关图片（若您使用） | 营养分析与记录展示 |

### 1.2 设备与传感器自动采集的信息

经您绑定本设备并授权后，通过本设备传感器及蓝牙同步采集，包括但不限于：

- **心脏与循环**：心率、静息心率、HRV、血氧饱和度、心电图（ECG）及波形摘要、相关算法风险提示（仅供参考，非诊断结论）
- **活动**：步数、运动距离、卡路里、运动类型与强度、运动会话记录
- **代谢与活动负荷**：梅脱（MET）时序及衍生活动负荷统计（视设备支持而定）
- **睡眠**：入睡/醒来时间、睡眠时长、睡眠分期、睡眠质量相关评分
- **身体状态**：皮肤温度、压力指数、血压、血糖、尿酸、血脂（总胆固醇、甘油三酯、HDL、LDL 等，视设备型号与功能开关而定）
- **身体成分**：体重、BMI、体脂率、肌肉量/率、体水分、内脏脂肪、基础代谢、骨量/蛋白质等（视设备型号与功能开关而定）
- **综合健康检测（微体检）**：单次测量内组合采集的多项指标及结果摘要（非医疗机构体检）
- **设备信息**：设备型号、固件版本、蓝牙 MAC、电量、同步日志与故障记录

### 1.3 使用过程中自动产生的技术信息

- 操作系统版本、应用版本、设备标识符、IP 地址、崩溃日志、接口请求时间
- **产品分析数据**（经您同意隐私政策后）：功能使用统计、页面访问等，**不包含**原始心率、血氧、睡眠分期等健康原始数据

### 2.1 算法与智能技术说明

**核心分析能力**由本公司自主研发和积累，包括但不限于：传感器信号处理、健康指标计算、睡眠/运动/恢复评估、身体成分评估、微体检综合参考、代谢负荷（MET）分析、元气趋势、异常趋势识别等，可在端侧或境内云端运行。个性化建议所依据的评分、趋势与风险提示，**主要由上述 Awak 专有能力产生**。

**人工智能辅助**用于在核心分析完成后，结合您的健康指标生成更贴合个人的参考建议与说明性文字，**不替代** Awak 核心健康分析，亦**不构成医疗诊断**。

我们**不会**将您的健康数据用于定向广告、保险核保营销或出售给数据经纪人。

### 2.2 人工智能推理服务的数据范围

为实现 §2.1 所述个性化建议与说明，在经您授权的前提下，我们可能向境内委托的人工智能推理服务提交以下信息（**数据不出境**）：

**可能提交的信息：**

| 类别 | 示例（以您已开启的功能为准） |
|------|------------------------------|
| 健康指标与统计结果 | 心率、静息心率、HRV、血氧、睡眠评分/时长/分期、活动量与运动摘要、压力指数、元气相关指标、营养摄入摘要、身体成分摘要、微体检结果摘要、尿酸/血脂趋势摘要、MET/活动负荷摘要等 |
| Awak 分析结论 | 由 Awak 算法先行计算的趋势、评分、恢复与疲劳相关摘要 |
| 基础身体信息 | 性别、出生日期（或年龄段）、身高、体重等（用于生成合理建议） |

**不会向人工智能推理服务提供：**

- 手机号码、姓名、证件号码、账号 ID、设备 MAC 等**可直接识别您身份**的字段；
- 心电图（ECG）**原始波形**等实现相关功能所不必要的高颗粒度明细；
- 用于广告、营销或与核心服务无关的目的。

**说明**：健康指标与统计结果在个人信息保护意义上可能属于敏感个人信息；我们仅在您授权范围内、为提供个性化健康参考之目的，按最小必要原则提交，并通过合同约定受托方不得用于其他用途。

### 2.3 AI 健康管家对话服务说明

「AI 健康管家」是您可通过应用内聊天入口与智能对话服务交流、获取个性化健康生活参考的功能。

**服务范围**：本功能仅提供**健康生活参考**（如作息、饮食、运动等日常健康知识与建议），**不提供、也不构成医疗诊断、用药或治疗建议**。若您的提问涉及疾病诊断、用药、治疗方案等内容，我们将不予解答，并建议您前往正规医疗机构就诊。

**请勿主动提供的信息**：为保护您的信息安全，我们**不建议**您在对话中主动提供病史、既往诊断、正在使用的药物等医疗相关敏感信息；即使您主动提供，本功能也**不会**针对该类内容给出解答。

**数据处理方式**：为回答您的问题，我们可能结合 §2.2 所列的健康指标、Awak 分析摘要、基础身体信息，以及**您在对话中主动输入的文字内容**，提交至境内委托的人工智能推理服务生成回复（**数据不出境**，排除规则与 §2.2 一致，即不含可直接识别身份的字段、不含 ECG 原始波形等高颗粒度明细）。对话内容将加密存储于我们的境内云端服务器，用于维持对话连续性、内容安全审计与功能改进，存储期限与账号存续期一致（详见 §六）。

**责任说明**：

- 若因**我们自身未履行必要的安全保障义务**（如系统安全漏洞、数据存储或传输环节的安全事故）导致您在对话中提供的信息被泄露，我们将依法承担相应责任；
- 若您**主动在对话中披露**病史、用药等医疗相关敏感信息，该等信息内容本身的性质及您自愿披露行为所引发的后果（不涉及我方安全保障义务缺失的情形），我们不承担因此产生的责任，请您审慎判断是否在对话中透露此类信息。

### 2.4 本机号码一键登录说明

「本机号码一键登录」是在**中国大陆**（cn 应用包）场景下，经您**勾选同意**《用户协议》《隐私政策》及**年龄确认**后，通过**阿里云号码认证 SDK** 与**电信运营商**（中国移动 / 中国联通 / 中国电信，以您 SIM 卡所属运营商为准）网关，核验本机手机号码并完成登录或静默注册的功能。

**处理流程（概要）**：

1. 您勾选相关协议并确认年龄后，我们方在客户端初始化号码认证 SDK 并预取号；
2. 您点击「本机号码一键登录」后，SDK 拉起**运营商授权页**（授权页内展示运营商服务条款，由运营商提供，**不**由本政策替代）；
3. 您确认授权后，SDK 返回登录凭证；我们的**境内服务器**调用阿里云号码认证服务校验该凭证，取得您的**本机手机号码**并完成登录或注册；
4. 若预取号失败、您取消授权或网络环境不满足（如无蜂窝网络），该功能不可用或失败，您仍可使用**短信验证码**等方式登录，**不会因此阻断**使用本应用。

**我们直接获取的信息**：经上述流程核验通过的**手机号码**（用于账号登录、注册与安全校验）。

**SDK 与运营商可能采集的信息**（为实现一键登录所必需，由 SDK 在本机采集并按阿里云及运营商官方披露处理；**我们不在此重复列举全部技术字段**）：

## 六、信息的存储与保护

### 6.1 存储地点与期限

- 个人信息与健康数据存储于**中华人民共和国境内**阿里云服务器；
- 账号存续期间，我们为提供趋势对比持续保存相关数据；
- 您注销账号且 7 日冷静期届满后，我们将删除或匿名化与您关联的个人数据；
- **审计脱敏日志**（不含可直接识别个人的健康明细）最长保留 **3 年**，用于安全审计与纠纷处理。

### 6.2 安全措施

传输采用 TLS/SSL 加密；存储采用访问控制与加密措施（如 AES）。尽管已有合理保护，互联网传输无法保证绝对安全。

### 6.3 跨境传输

**我们当前不向境外提供个人信息。** 若未来业务需要跨境传输，我们将依法进行安全评估并征得您的单独同意。
